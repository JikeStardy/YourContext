# 🧠 YourContext

> 🌟 **让AI成为你的第二大脑** 🌟

一个用于存储个人记忆并由大模型Agent进行智能分析的项目。将你的日常想法、笔记、经验存储在这里，让AI帮助你发现洞察、建立联系、提供建议。

## 🌈 项目特色

- 📝 **个人记忆存储**: 安全存储你的笔记、想法、经验和重要信息
- 🤖 **AI智能分析**: 大模型Agent分析你的记忆，发现模式和洞察
- 💬 **智能问答**: 基于你的记忆库回答个性化问题
- 🔗 **关联发现**: 自动发现记忆之间的隐藏联系
- 📊 **趋势分析**: 追踪你的想法和行为模式变化
